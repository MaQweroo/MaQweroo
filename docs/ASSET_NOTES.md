# Asset notes

## Banners

Source reference: user-supplied `github.jpg`, a 1024 × 2048 screenshot.
Method: built-in image generation using the screenshot as a visual reference.
`header-city.png`: reconstruction of the upper grayscale industrial city/workstation scene.
`footer-garden.png`: reconstruction of the lower pixel-art Japanese garden scene.
These are reconstructed illustrations, not exact source crops. Original names, code, logos and interface elements were removed. The banners are static PNGs.
Exact generation prompts are in `IMAGE_PROMPTS.txt`.
